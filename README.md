# krita-layer-tag-manager

A Krita plugin for tagging, searching, and batch-managing layers with persistent presets and full undo support.

## Stack

Primary language: **Python**

## Project structure

- `krita_layer_tag_manager.py` — Provides a dockable widget for layer metadata management, advanced filtering, and batch operations.
- `requirements.txt` — dependencies
- `tests/test_main.py` — basic tests

## Usage

Review the source files and install any dependencies referenced by the project before running it.
